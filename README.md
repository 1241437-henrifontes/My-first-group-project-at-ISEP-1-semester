# My first group project at ISEP - 1º Semester
This is the first project i developed at ISEP, in my first semester, with a group of 3 more members. 

The basis of the project was the creation of a program that'd work with facial recognition with eigenfaces.  

The objective was to create a program that'd had **4 functionalities**:

1. Resize images (images are given as input and in CSV)
2. Rebuild images
3. Identify the most similar image/face to a initially given one
4. Generate a new image/face based on a images/faces data base
